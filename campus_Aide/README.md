# 校园智汇 —— 课表协同与任务预警系统

基于 Streamlit 的校园任务协同工具。它保留原项目的双向查询、红黄绿看板、OCR 导入、一键演示数据和 CSS 组件，并将业务改为课程/项目、具体任务和任务分配。

## 本地运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

核心规则：`任务截止日 - 3 天 = 必须启动日`。

- 🔴 急：今天必须开始做
- 🟡 缓冲：这几天做就行
- 🟢 不急：本周内完成即可

OCR 页面支持 PNG、JPG、WebP 和 PDF。上传课表截图后，系统会提取课程/项目、具体任务、数量和任务截止日期；识别结果必须核对后才会保存。

数据默认写入临时的演示会话目录。部署到需要持久化数据的环境时，可设置 `CAMPUS_DATA_DIR`。
