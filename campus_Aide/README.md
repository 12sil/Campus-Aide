# 校园智汇 · 我的校园生活计划

把大学生活里真正需要推进的事情放在一起：作业、考试、社团、比赛和临时安排。

## 现在的核心模块

- **我的一天**：按截止日期显示今天最值得关注的事项，支持“开始做”和“完成打卡”。
- **记一件事**：不用先建立复杂档案，直接写下任务、归属和截止日期。
- **课程与活动**：按课程、考试、社团或竞赛查看计划和完成进度。
- **截图转计划**：上传课程通知、作业要求或活动安排截图，识别后生成待办。
- **调整任务状态**：保留取消、恢复和更正记录。

## 运行

```bash
pip install -r requirements.txt
streamlit run app.py
```
